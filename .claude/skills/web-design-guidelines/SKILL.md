# Web Interface Guidelines review

Review the given files (or the files changed on this branch if none are given) against the rules in [guidelines.md](./guidelines.md), a local copy of https://github.com/vercel-labs/web-interface-guidelines.

1. Read [guidelines.md](./guidelines.md).
2. Read the target files.
3. Check every rule that applies and report findings in the terse `file:line` format the guidelines describe.

Project rules in `FRONTEND_GUIDELINES.md` win where the two disagree.
